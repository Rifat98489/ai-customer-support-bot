# 🤖 AI Customer Support Chatbot (Powered by Groq & Streamlit)

A scalable, high-performance, and cost-effective AI Customer Support Assistant built with Python, Streamlit, and Groq API using Meta's high-speed `llama-3.3-70b-versatile` LLM.

---

## ✨ Key Features
- **⚡ Ultra-Fast Responses:** Leverages Groq's LPU Inference Engine for near-instant responses.
- **🔒 Dynamic API Key Management:** Users can input their Groq API Key securely via the sidebar.
- **🎯 Business-Ready Architecture:** Designed to easily inject custom system instructions, FAQs, and brand-specific support personas for clients.
- **💬 Conversational Context:** Retains active chat session memory for natural multi-turn conversations.

---

## 🛠️ Tech Stack & Dependencies
- **Frontend / Framework:** Streamlit
- **LLM Engine:** Groq API (`llama-3.3-70b-versatile`)
- **Language:** Python 3.10+
